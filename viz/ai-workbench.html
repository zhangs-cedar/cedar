AI 工作流展示层

把 Markdown、JSON、Python 留作工程底稿，把复杂报告、方案对比和实验分析发布为 Cedar 上的静态 HTML 展示面板。

sourceMarkdown / JSON

工程底稿，可 diff、可复用。

generatorPython

读取源数据，生成静态产物。

artifactCedar HTML

网页查看、搜索、筛选和展示。

当前规则

Markdown 不退场；它变成底稿。HTML 也不变成源文件；它变成可再生展示面板。

本页源数据来自 content/ai_workbench.json，由 scripts/generate_ai_workbench.py 生成。

原则

Markdown 做 source

规范、规则、设计草稿、提示词和长期说明继续使用 Markdown，便于 diff、审阅和版本控制。

JSON / CSV 做 data

实验指标、样本索引、方案评分和代码审查结果保存为结构化数据，避免把业务数据写死在页面里。

HTML 做 artifact

需要搜索、筛选、折叠、表格排序、图片网格或方案对比时，生成单文件 HTML 并挂到 Cedar。

Cedar 做 viewing layer

展示层集中放在 Cedar 的 viz/ 目录，主页提供入口，核心项目只保留源文档和生成脚本。

分层架构

LayerPathFormatsPurpose
Source docs/ 或 content/ Markdown / YAML / JSON / CSV 长期可维护的工程事实、实验数据和规则。
Generator scripts/ 或 tools/ Python 读取源数据，生成可发布 HTML；脚本是展示层的单一生成入口。
Artifact viz/*.html HTML + inline CSS + inline JS 可交互报告、实验看板、方案对比和代码审查视图。
Navigation index.html 静态入口页 集中发现所有可视化与工作流展示页面。

HTML 产物标准

生成约束
  • 单文件 HTML，内联 CSS 和 JS，不依赖外部 CDN。
  • 数据区和展示区分离，页面内保留 application/json 数据块。
  • 支持搜索、筛选、折叠、表格排序和复制按钮。
  • 移动端可读，桌面端信息密度高。
  • 重要 HTML 必须能从 Markdown / JSON / Python 重新生成。
  • 不要把 Cedar 生成产物当长期源文件手工维护。

可复制提示词

生成实验报告

请读取当前项目的 experiments/ 目录和指标 JSON，生成一个 Cedar 可发布的单文件 HTML 报告。要求：数据和展示分离；支持目录导航、折叠区块、表格排序、关键词搜索；输出到 cedar/viz/experiment_report.html；不要修改核心训练代码。

生成代码审查展示页

请把本次代码审查发现整理成 JSON 源数据，并生成 Cedar 的 HTML 展示页。页面包含严重程度筛选、文件筛选、风险标签、建议修改和可复制 patch 区块。
